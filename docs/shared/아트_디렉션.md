# 아트 디렉션

이 프로젝트의 비주얼 목표·규칙·에셋 판단 기준. (맵 제작 방식은 [MAP_제작_가이드](MAP_제작_가이드.md) 참고.)

---

## 1. 목표 룩 — 세미 스타일라이즈드 사이버펑크

**레퍼런스 2장 사이의 중간 지점, 이미지 2(밀집 네온 사이버펑크) 쪽에 더 가깝되 포토리얼은 아님.**

- 이미지 1(네온 로우폴리 아레나) = **너무 단순** (완전 로우폴리 X).
- 이미지 2(실사 밀집 사이버펑크 골목) = **색·네온 밀도·무드는 목표**, 단 표면의 포토리얼 그림·때(grime)까지는 안 감.
- 착지점 = **세미 스타일라이즈드**: 깔끔한 형태 + 강한 emissive 네온 + 무거운 포스트. 표면 디테일보다 **빛과 색**으로 밀어붙인다.

### 왜 이 타깃인가 (제작 논리)
- 무드의 **절반 이상이 조명·포스트**(Bloom·컬러 그레이딩·안개·emissive)에서 나옴 → 소규모 팀에 유리.
- 포토리얼 PBR은 텍스처·라이트맵·때 작업이 지옥 → 세미 스타일은 그걸 우회.
- 현재 **그레이박스 + emissive + Bloom** 파이프라인이 이미 이 방향의 뼈대.

---

## 2. 세팅 (배경 설정)

- **주무대 = 실내 실험실/감옥.** 강한 플레이어를 가둔 시설. (둠식 봉인 해제 인트로와 연결.)
- **야외 = 게임 마지막에 딱 한 번** (최종 아레나, 카메라 쭉 당겨 정경 보여주는 컷신).
- → 비주얼 리소스 우선순위: **실내(랩·감옥·시설) 압도적 우선.** 야외 도심은 최종전용 최소 1세트.

---

## 3. 공간 역할 분담 — 플레이필드는 비우고 디테일은 가장자리로

액션 가독성 규칙. **두 레퍼런스는 대립이 아니라 역할 분담이다.**

| 영역 | 룩 | 이유 |
|---|---|---|
| **바닥·전투 동선** | 이미지 1처럼 **클린**. 비어 있고 읽기 쉬움. | 근접 액션에서 적 위치·투사체·이동 라인이 한눈에 보여야 함 |
| **벽·천장·배경·주변부** | 이미지 2처럼 **네온 빽빽**. 간판·파이프·케이블·광원. | 무드·밀도는 여기서 담당 |

→ 밀도를 플레이 바닥까지 깔면 적을 못 읽는다. **디테일은 항상 주변부로 밀어낸다.**

---

## 4. 룩 구성 요소 (무드는 여기서 만든다)

에셋이 아니라 **라이팅·포스트가 사이버펑크 느낌을 결정한다.**

- **어두운 베이스** — 전체적으로 로우키. 어둠 위에 네온이 떠야 대비가 산다. (단, 마냥 어둡지 않게 — 네온이 공간을 읽게 해줌.)
- **강한 emissive 네온** — 간판·라인·경광등·홀로그램. 색은 시안/마젠타/블루 주축 + 위험 구역 레드.
- **Bloom** — 네온 번짐. 사이버펑크의 핵심. 과하지 않게 튜닝.
- **컬러 그레이딩** — 마젠타/시안으로 채도 밀어올림. (이미지 2의 보라·핑크 톤.)
- **안개(Fog)** — 깊이감·네온 산란. 실내에도 옅게.
- **젖은 바닥 반사** — 리플렉션 프로브로 네온 반사. 사이버펑크 시그니처.
- **배치 광원·경광등** — 맵 곳곳에 실제 광원. 봉인 해제·위급 상황엔 붉은 경광·점멸로 긴장 연출.

---

## 5. URP 한계 (중요 — 구매·구현 판단에 영향)

우리는 **URP**다. 포토리얼 사이버펑크가 잘 나오는 HDRP와 다르다.

- **SSR(화면공간 반사) 약함** → 젖은 바닥 반사는 **리플렉션 프로브 + 에셋/커스텀 셰이더**로 우회.
- **볼류메트릭 안개 약함** → 에셋(볼류메트릭 라이트 팩) 또는 파티클/커스텀으로 보강.
- → 세미 스타일 타깃이라 이 한계가 **오히려 부담이 덜함** (포토리얼 반사·안개에 목맬 필요 없음). emissive+Bloom+그레이딩으로 대부분 커버.

---

## 6. 에셋 판단 기준 (구매 시 체크)

세팅·타깃에 맞춰 좁힌 기준.

- [ ] **스타일** = 세미 스타일라이즈드 사이파이/사이버펑크. (포토리얼 HDRP 메가팩 ✗ — 오버·변환부담. 만화풍 로우폴리 ✗.)
- [ ] **렌더 파이프라인** = **URP 네이티브** 우선. Built-in은 변환 가능하나 확인 필요. HDRP는 지양.
- [ ] **emissive 강함** — 네온이 살아있는 팩. (스크린샷에서 발광 확인.)
- [ ] **모듈러** — 타일링으로 크기 자유(랩·감옥·복도 조립).
- [ ] **실내 우선** — 랩·감옥·시설 인테리어. 야외 도심은 최종전 1세트만.
- [ ] **소품 별도 보강** — 간판·파이프·케이블·모니터·경광등 소품팩으로 밀도.
- [ ] **룩 통일** — 환경·소품·몹이 한 스타일. 뒤섞이면 안 됨.

---

## 요약
- **세미 스타일라이즈드 사이버펑크** (이미지 2 무드, 포토리얼 X).
- **실내 랩/감옥**이 주무대, 야외는 최종전 1회.
- **플레이필드 클린 / 주변부 네온 빽빽.**
- **룩은 조명·포스트(Bloom·그레이딩·안개·emissive·젖은반사)가 결정.** 에셋은 형태+네온소품용.
- 에셋은 **URP 네이티브 · emissive 강한 · 스타일라이즈드 실내 킷** 우선.
