# 레벨 구성 뼈대 (초안)

> **상태: 기본 뼈대 (확정 아님).** 세부(적 수·배치·수치·공간 형태)는 **맵을 만들면서** 정한다.

전체 진행: **복도 ↔ 아레나** 반복 → 최종 야외 전장. 복도=학습/완급, 아레나=가둠+웨이브+전멸.

## 몹 약칭
근(근접) · 원(원거리) · 돌(돌진) · 공(공중) · 근층/원층(층이동 변종) · 대(대형 접두사, 예: 대근).

## 흐름

| 구간 | 내용 | 적 |
|---|---|---|
| **복도1** (봉인해제방) | 봉인해제 컷신 → 칼습득 컷신 | 길목에 근 몇 |
| **아레나1** | | W1: 근 / W2: 근 / W3: 근·원 |
| **복도2** | **예지가면 습득** (예지 시험용으로 예쁘게 꾸밀 장소) | 앞에 근 다수 |
| **아레나2** | | W1: 근·근층·원 / W2: 근·근층·원·원층 / W3: 근·근층·원·원층 |
| **복도3** | | 돌 몇 |
| **아레나3** | | W1: 돌 다수 / W2: 근·근층·돌 / W3: 근·근층·돌·원·원층 |
| **복도4** | | 근·공 (공 위주) |
| **아레나4** | | W1: 근·근층·공 / W2: 근·근층·공·원·원층·돌 |
| **복도5** | 좁은 길목 | 근 몇 |
| **아레나5** | | W1~W3: 근·근층·원·원층·돌·공 |
| **복도6** | 아무것도 없는, 좁지만 **점점 넓어지는** 골목 | 끝 문에 **대근 2** |
| **아레나6** (최종·유일한 야외) | 기획 예정 | 전 몹(대형 포함) 다수, 가능하면 **보스** |

## 방향
- 플레이어가 몹을 **천천히** 배우도록 복도→아레나로 소개·시험.
- **대형은 복도6에서 잠깐(대근 2) 첫 등장 → 최종전장에서 다수.**
- 예지가면은 복도2에서 습득, 이후 아레나에서 실전 도구화.
