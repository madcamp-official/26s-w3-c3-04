# 개발 콘솔 · 웨이브 테스트

## 콘솔 열기
- **`` ` ``**(백쿼트) 토글 · **Esc** 닫기
- 열려 있는 동안 플레이어 조작만 멈춤(시뮬레이션은 계속 돎 → 소환한 몹 관찰 가능)
- `help` 치면 명령 목록

## 웨이브 명령 (번호는 **1부터**)

| 명령 | 설명 |
|---|---|
| `wave start` | 웨이브1부터 **순차 진행**(조건 충족 시 자동으로 다음) |
| `wave start 2` | 웨이브2부터 순차 진행 |
| `wave only 2` | **웨이브2만** 실행, 다음으로 안 넘어감 |
| `wave list` | 아레나·웨이브 목록 (W1:20마리 …) |
| `wave status` | 현재 상태 (웨이브·단계·스폰 n/총·생존) |
| `wave stop` | 중단 |

- 실행 중에 다른 `wave only N`을 치면 **덮어쓰고 새로 시작**(이전 몹은 남음 → 필요하면 `clear`)
- 아레나가 여러 개면 **플레이어에게 가장 가까운 아레나**를 잡음

## 몹 소환

| 명령 | 설명 |
|---|---|
| `spawn <종류>` | 정면 6m에 1마리 |
| `solo <종류>` | 전부 지우고 1마리만 (자동소환 off) |
| `clear` | 몹 전부 제거 |
| `count` | 생존 수 |
| `autospawn on\|off\|reload` | 기존 자동소환 토글 |

**종류**: `grunt`(근) `pinky`(돌) `soldier`(원) `caco`(공) `large`(대) `gruntt`(근층) `soldiert`(원층)
한글 별칭도 됨: `근층` `원층`

## 현재 테스트 웨이브 구성

| | 총 | 구성 | 배관 |
|---|---|---|---|
| **W1** | 20 | 근 7 · 근층 7 · 돌 6 | 10개 |
| **W2** | 20 | 근 4 · 근층 4 · 돌 2 · 원 3 · 원층 3 · 공 4 | 10개 |
| **W3** | 7 | 공 7 | 4개 |

- **전 배관 동시 시작**, 배관 하나가 **1.5초 간격**으로 자기 몹을 뱉음
- 진행 조건: **전멸**(다 잡아야 다음 웨이브)
- 스폰 시 배관 바깥(마커 **노란 면**) 방향으로 **펄스**를 받고 튀어나옴 → **착지 전까지 공격 안 함** (공중몹은 0.5초 뒤 공격)

## 구성 바꾸기

- **자동 생성/재생성**: `Tools/맵 부속/테스트 웨이브 생성`
  - 마리 수는 `Assets/_Project/Editor/ArenaWavesEditor.cs` 의 `QuotaOf(wave, kind)` 숫자만 고치면 됨
- **수동 편집**: 씬의 `_Waves` 오브젝트 → `ArenaWaves` Inspector
  - 배관마다 몹 목록·순서·간격·시작지연을 개별 설정
  - 마커를 선택하고 Inspector 하단 **"선택한 마커를 웨이브 N에 배관으로 추가"**

## 알려진 것

- **근층/원층은 맵에 traversal 링크가 있어야** 실제로 층을 넘나듦. 없으면 일반 지상몹처럼 움직임.
- `ArenaWaves.spawnDropOffset`은 **벽 끼임 회피용 임시값**. 펄스가 안정되면 0으로 되돌릴 것.
