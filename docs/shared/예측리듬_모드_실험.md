# 예측 경로 추종 리듬 — 재미 실험 모드 (2026-07-22)

"예측 경로 확정 후 박자 맞추기가 밋밋하다"는 피드백에 대한 실험판. **판정기(RhythmJudge)와 경로
재생 파이프라인은 그대로 두고**, "박자 하나를 어떻게 치게 만드는가"만 갈아끼우는 레이어를 얹었다.

- 구현: `Assets/_Project/View/Prediction/PredictionRhythmModes.cs` (신규, 모드 전부 여기 있음)
- 연결 지점: `PredictionController.cs` — `AddRhythmInput` / `BeginRhythmSegment` / `Confirm` /
  `Exit` / Miss 처리 / `DrawRhythmHud` 5~6군데에 훅만 넣었다. 모드 레이어를 통째로 지우면
  기존 동작(Classic)으로 정확히 돌아온다.
- 튜닝값은 전부 `RhythmModeConfig`에 모여 있다.

## 전환 방법

예지(F) **밖 또는 미리보기 중**에 **숫자키 1~5**. 화면 좌상단에 현재 모드와 설명이 뜬다.
선택은 PlayerPrefs에 저장돼 다음 실행에도 유지된다. (실행 중 전환은 박자 상태가 꼬여서 막아뒀다.)

## 모드 5종

| 키 | 이름 | 노림수 | 규칙 |
|---|---|---|---|
| 1 | CLASSIC | 기준선(기존 동작) | 박자마다 지정 키 1번. Miss = 예지 해제 |
| 2 | MASH | **참여도** — "다다다" | 박자 전까지 같은 키를 연타해 5칸 게이지를 채우고, 채운 상태로 박자에 맞춰 마지막 타. 0.28초 이상 쉬면 게이지가 샌다(초당 4.5칸). 요구치를 넘겨 더 두들기면 OVERDRIVE 보너스 |
| 3 | FREESTYLE | **자유도** | 아무 액션 키나 박자만 맞으면 통과(실행되는 액션은 예측대로). 정확한 키를 골라 치면 EXACT 보너스. **Miss해도 예지가 안 풀리고 콤보만 끊긴다** |
| 4 | HIGHWAY | **리듬게임화** | 접근링 대신 노트 레일 HUD — 다음 박자 5개가 판정선으로 내려온다. 판정 규칙은 Classic과 같고, **Miss해도 곡처럼 계속 간다** |
| 5 | COMMAND | 참여도 + 손맛 | 박자 하나가 3연 커맨드로 확장(예: A → W → 좌클릭). 앞 두 칸은 "장전"이고 마지막 입력이 실제 판정. 틀리면 커맨드가 처음으로 리셋(BREAK) |

공통으로 **콤보·점수**가 얹힌다(우상단). Perfect 300 / Good 150 + 콤보×10, 모드별 보너스.
루트가 끝나면 콘솔에 `[예측 리듬] <모드> 결과 — 점수, 최대 콤보`가 찍힌다.

## 설계 메모 / 각 모드가 노리는 것

- **MASH**: 박자 사이의 "빈 시간"이 밋밋함의 주범이라 봤다. 그 구간을 연타 충전으로 채워
  손이 계속 바쁘게 만든다. 게이지 감쇠 때문에 느긋하게 누르면 안 차고, 실제로 "다다다" 쳐야 한다.
- **FREESTYLE**: 정답 키를 외워 치는 스트레스를 없애고 타이밍만 남긴다. 대신 정타에 보너스를
  줘서 "제대로 치면 더 좋다"는 층을 남겼다. 경로 재생은 결정론이라 실행 액션 자체는 못 바꾼다 —
  진짜 자유도(분기 선택)를 주려면 예측을 여러 갈래로 뽑아 재계획해야 하고, 그건 별개 작업이다.
- **HIGHWAY**: 지금은 "다음에 뭐가 올지"가 화면 옆 작은 NEXT 하나뿐이라 예측·기대감이 없다.
  노트를 5개 미리 보여주면 리듬게임의 선행 읽기 쾌감이 생긴다. Miss로 안 끊기니 흐름도 유지된다.
- **COMMAND**: 격겜식 커맨드 입력의 손맛. 한 박자에 입력 3개가 들어가 참여도가 제일 높지만
  난이도도 제일 높다 — 길이는 `RhythmModeConfig.SequenceLength`로 조절.
