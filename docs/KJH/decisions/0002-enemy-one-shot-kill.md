# ADR-0002: 적 전부 한방컷 (health 필드 없음)

- 날짜: 2026-07-17
- 상태: 확정

## 결정

중형몹을 포함한 모든 적은 한방컷(one-shot kill). 적 상태(`EnemySimState`)에 **`health` 필드를 두지 않는다.**

## 이유

예측 시뮬레이션에서 적의 체력을 추적하면 경로 계산이 복잡해진다. 한방컷이면 경로 평가가 **"죽는다 / 안 죽는다"의 이진 판정**이 된다. 적이 두 방 이상 걸리는 순간, Beam Search가 "이 경로로 각 적을 몇 대 때리나"까지 추적해야 하고 탐색 공간이 폭발한다.

플레이어 HP를 낮게 잡은 것도 같은 맥락 — 예측을 쉽게 만들기 위해서다.

## 고려했던 대안

- 적 HP 2~3: 탐색 복잡도 폭증으로 기각.
- `health` 필드를 두되 값을 1로 고정: 누군가 반드시 2를 넣게 되므로 필드 자체를 제거하는 편이 안전.

## 영향

- **나중에 플레이어 HP를 올리더라도 적의 한방컷은 유지한다.** 이건 밸런싱 여지가 아니라 구조적 제약이다.
- 처치는 이진 이벤트다 → 스턴 같은 중간 상태([0005](0005-dash-to-iaijutsu.md))는 별도 필드로 관리하되, 체력은 없다.
- 팀원 문서 v1.1에 있던 `EnemySimState.health`는 제거 대상 ([검토](../reviews/2026-07-17-teamdoc-v1.1.md) 4번 항목).
