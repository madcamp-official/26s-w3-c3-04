# ADR-0006: 적 HP 2~3 + 만능 스턴 (한방컷 폐기)

- 날짜: 2026-07-18
- 상태: **부분 대체됨** — HP·피해·스턴은 유지, 입력·이동기는 [ADR-0007](0007-four-way-dash-and-target-lunge.md)로 대체
- 대체: [ADR-0002](0002-enemy-one-shot-kill.md) (적 한방컷)

## 결정

적을 한방컷에서 **HP 2(일반) / 3(중형)**로 바꾼다. `EnemyState`에 `health` 필드를 다시 둔다. 그리고 **모든 대미지원(평타·질풍참·칼등치기)은 대미지 1 + 스턴 0.5초로 통일**한다.

> 수치(HP 2/3, 대미지 1, 스턴 0.5초)는 전부 **잠정·튜닝 대상**.

## 이유

새 전투 루프가 **스턴 세팅 → 마무리** 구조다:

1. 아무 공격이나 맞히면 대미지 1 + 스턴 0.5초 → 적이 얼음
2. 0.5초 안에 한 번 더 쳐서 마무리 (HP2 = 두 대)

**이 루프는 적이 첫 타를 버텨야 성립한다.** HP1(한방컷)이면 스턴 걸 새도 없이 즉사해서, 스턴·칼등치기·세팅 개념이 전부 무의미해진다. 즉 **새 전투가 HP>1을 요구한다.** ADR-0002의 "한방컷으로 예측 단순화"보다, 이 전투 깊이가 더 가치 있다고 판단.

## ADR-0002를 뒤집는 것의 대가 (정직하게)

ADR-0002가 한방컷을 택한 이유는 예측을 **이진(죽는다/안 죽는다)**으로 단순화하기 위해서였다. HP>1이면:

- 예지가 **미래 내내 적 HP를 추적**해야 한다 (경로마다 각 적을 몇 대 때리는지).
- 지연·스턴 타이머도 예약된 틱으로 추적.

**감당 가능한 이유**: HP가 2~3으로 작고 유한하다. 탐색이 이진보다 복잡해지지만 폭발하진 않는다. 그리고 스턴 0.5초가 "한 번 맞히면 마무리 확정"에 가까워, 실질 분기는 "첫 타를 맞히느냐"로 단순화되는 면도 있다.

## 영향

- `EnemyState`에 `health` 부활 (일반 2, 중형 3). 예지 탐색이 HP 소비를 추적.
- 모든 공격에 스턴 0.5초 부여 → 스턴 타이머를 상태·해시에 포함.
- ADR-0005(질풍참) 개정: 대미지 0 → 대미지 1 즉발.

### 입력·방어 구조 — 대체된 기록

> 아래 막기·칼등치기·질풍참 내용은 ADR-0007에 의해 폐기되었으며 역사 기록으로만 남긴다.

한 번 "막기 폐기"로 갔다가 되돌렸다. 최종(잠정):
- **우클릭 홀드 = 막기** (부활). 정면, 가드 게이지 소모.
- **막기 중 좌클릭 = 칼등치기** (브리기테 방패밀치기식). 이동보정 + **넉백**(공중 포함) + 대미지 1 + 스턴 0.5초. **쿨 없음, 가드 게이지 1/4 소모**, 자기경직 없음/후딜 ~0.1초.
- 가드 게이지가 막기·칼등치기 **공용 자원**. HUD는 세로 막대(가드 흰 + 질풍참 빨강), 가드 4등분.
