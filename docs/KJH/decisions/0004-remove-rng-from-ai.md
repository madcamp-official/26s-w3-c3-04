# ADR-0004: 적 AI 난수 제거 (개체별 고정 상수는 예외 — 2026-07-20 개정)

- 날짜: 2026-07-18
- 상태: **부분 개정** (2026-07-20) — 원 결정의 "난수 완전 제거"를 **"판단 시 난수 금지"** 로 좁힘. §개정 참조.

## 결정 (개정 반영)

적 AI의 **행동 판단에는 난수를 쓰지 않는다.** 매 틱·매 판단마다 굴리는 난수(진행하는 rng 인덱스,
랜덤 공격 타이밍)를 금지한다. 적 행동은 **상태 머신 + 우선순위 결정 트리**로 선택한다.

동일한 월드 상태에서는 거리·높이·시야·경로 가능 여부·공격 상태를 **같은 순서로 평가**해 항상 같은 행동을 선택한다.

**단, 스폰 시 개체별로 한 번 정해지고 이후 변하지 않는 상수는 허용한다**(§개정).

## 배경

초기 GDD는 "시드 고정 후 예지 발동 순간 5초치를 미리 굴려 액션 큐로 저장"하는 방식이었다. 팀원 문서 v1.1이 이를 한 단계 더 밀어 **난수 자체를 없애는** 방향을 제시했고, 이쪽이 낫다고 판단해 채택한다.

## 이유

- **더 강한 결정론**: 시드 관리, 큐 저장/소비, 재생 시 큐 동기화가 전부 사라진다.
- **디버깅이 쉽다**: "왜 이 적이 이렇게 행동했나"를 난수가 아니라 규칙으로 설명할 수 있다.
- **동률 해소만 명시하면 완전 결정론**: `entityId` 오름차순, `nodeId`/`linkId` 사전순, 겹침 시 `entityId` 홀짝 분리 (팀원 v1.1 7.7, 7.8).

## 트레이드오프 (감수)

적이 완전히 예측 가능해져 **패턴이 단조로울 수 있다.** 같은 상황에서 항상 같은 행동을 하므로 플레이어가 외울 여지가 있다. 다만:
- 예측 시스템이 정체성인 게임에서 "적이 예측 가능"은 오히려 컨셉과 맞는다.
- 다양성이 필요하면 난수가 아니라 **결정론적 변수**(위치, 웨이브 배치, 초기 쿨타임 차등)로 만든다.

플레이테스트에서 단조로움이 문제되는지 관찰한다.

## 영향

- `EnemySimState`에 **판단 중 진행하는** 난수 필드(`rngDecisionIndex` 등)를 두지 않는다.
  (스폰 시 고정되는 개성 상수는 허용 — §개정)
- 컬렉션 순회 순서에 의존 금지 → `Dictionary` 대신 `entityId` 정렬 배열.
- 원거리 적의 동시 발사 문제는 판단 난수가 아니라 웨이브 배치·초기 쿨타임 차등·개체 고정 상수로 해결.

## 개정 (2026-07-20)

### 무엇이 바뀌나

원 결정의 "난수 **완전** 제거"는 과했다. **스폰 시 개체별로 한 번 정해지고 이후 절대 변하지 않는
상수(개성값)** 는 허용한다. 금지 대상은 **판단할 때마다 굴리는 난수**로 한정한다.

| | 허용 여부 |
|---|---|
| 스폰 시 개체별 **고정 상수**(개성값) | **허용** |
| 매 틱·매 판단마다 굴리는 난수, 진행하는 rng 인덱스 | 금지 |
| 랜덤 공격 타이밍(매번 다시 굴림) | 금지 |

### 왜 안전한가 (예측 결정론)

고정 개성값은 **엔티티 상태의 일부**다. 예측이 월드를 포크하면 그대로 복사되므로 재현된다.
"매 틱 굴리는 난수"가 위험했던 이유(포크 시 rng 스트림 동기화, 큐 저장/소비)가 여기엔 없다.

**요구 조건**:
1. 값은 **스폰 시 1회만** 결정되고 이후 불변.
2. `EnemySim`에 저장되어 **월드 상태**에 포함.
3. **`WorldHash`에 포함**되어야 한다(빠지면 포크 검증이 이 값의 차이를 못 잡는다).
4. 스폰 시 값 산출이 **결정론적**일 것 — 권장: `Hash(worldSeed, enemyId)`.
   `worldSeed`는 매치 시작 시 고정되어 월드 상태에 저장 → 매치 간에는 달라지되
   **매치 내에서는 불변**이라 포크에 안전.

### 첫 적용 대상: 분산(뭉치기 방지) 세기 개체차

현재 모든 몹이 **동일한 분리 가중치**를 써서, 정면으로 마주치면 밀어내는 힘이 대칭이 되어
거울처럼 진동하고 무리가 한 덩어리로 움직인다.

→ 개체별 고정 상수로 **분리 세기 배율**(최대치 대비 낮추는 곱)을 다르게 준다.
같은 상황에서도 몹마다 회피 강도가 달라 **자연스럽게 서로 비껴 지나간다.**

확장 여지(같은 방식):
- 플레이어 주변 **포위 각도 오프셋** — 일렬 줄서기 대신 자연스러운 포위.
- **리패스 주기·초기 쿨타임 위상차** — 전원이 같은 틱에 동시 행동하지 않게.

### 유지되는 원칙

행동 **선택**은 여전히 규칙 기반이다. 개성 상수는 "무엇을 할지"를 바꾸지 않고
**"얼마나 세게/어느 방향으로"** 같은 연속값에만 관여한다. 따라서
"왜 이 적이 이렇게 행동했나"는 여전히 규칙으로 설명된다(원 결정의 디버깅 이점 유지).
