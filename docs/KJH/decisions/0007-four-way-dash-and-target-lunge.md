# ADR-0007: 4방향 대시 + 타깃 런지

- 날짜: 2026-07-18
- 상태: **확정**
- 대체: [ADR-0005](0005-dash-to-iaijutsu.md)의 질풍참
- 부분 대체: [ADR-0006](0006-enemy-hp-and-universal-stun.md)의 막기·가드·칼등치기

## 결정

플레이어 전투 행동을 이동, 더블 점프, 4방향 대시, 좌클릭 평타, 우클릭 타깃 런지로 고정한다.

막기, 가드 게이지, 칼등치기, 기존 복합 질풍참은 제거한다.

## 4방향 대시

- 카메라 기준 전·후·좌·우
- 이동 전용
- 피해·스턴·무적 없음
- 시작 순간 방향 고정
- MVP는 1회 사용 후 약 1초 쿨타임에서 시작

## 타깃 런지

- 같은 층, 거리 이내, 정면 원뿔 안, LOS가 확보된 적만 대상
- 우선순위: 각도 → 거리 → `entityId`
- 시작 순간 `targetId`와 도착점을 고정
- 적 앞의 유효 지점으로 이동
- 피해 1과 짧은 스턴
- 무적 없음
- 약 2초 쿨타임에서 시작

런지 Travel 중 타깃이나 도착점을 다시 계산하지 않는다.

## 기본 전투 문법

```text
4방향 대시로 공격 회피
→ 정면 적에게 타깃 런지
→ 피해 1 + 스턴
→ 평타로 마무리
→ 대시 또는 일반 이동으로 이탈
```

## 이유

- 막기는 위험 경로를 가드 자원으로 통과하게 만들어 공간 예측의 의미를 약하게 한다.
- 기존 질풍참은 이동·공격·스턴·전면 방어가 한 버튼에 모여 지배적인 행동이 될 위험이 있다.
- 대시는 회피, 런지는 공격 진입으로 역할이 분리된다.
- 예지는 난전에서 타깃·진입·이탈 순서를 미리 계산하는 의미를 갖는다.
- 런지 후보를 가까운 1~2명으로 제한해 수십 마리 환경의 탐색 분기를 통제할 수 있다.

## 코드 영향

- `InputCmd.block` 제거
- `InputCmd.lunge`, `lungeTargetId` 추가
- 대시 방향을 4방향 enum으로 저장
- 런지 타깃 선정은 Sim 계층에서 수행
- 런지 도착점·쿨타임·행동 단계를 Snapshot과 WorldHash에 포함
- 경로 카드에서 가드 소모를 제거하고 대시·런지 사용 수와 예상 피격 수를 표시

MVP의 정확한 쿨타임과 행동 틱은
[`PREDICTION_CONTRACT.md`](../../shared/PREDICTION_CONTRACT.md)에 확정한다.
이후 튜닝은 가능하지만 계약 버전 갱신과 게임·예측 양쪽 리뷰 없이 임의로 바꾸지 않는다.
